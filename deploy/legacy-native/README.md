# 原生版本历史参考

本目录保存旧单前端、预览入口和旧测试。新版应用入口为根目录 `frontend-web/`、`frontend-admin/`、`backend/app/`，运行和构建配置以 `deploy/docker/`、`deploy/scripts/`、`deploy/cicd/` 为准。

旧版完整基线位于 Git 提交 `f62dc92dcee63d7368ba02757137deb2d0491e5b`；需要维护目前线上原生版本时使用该提交的独立检出，不要把本目录的部分历史文件和新版异步后端混合构建。本目录不作为新版 CI 的构建上下文。

根目录仍保留原生部署/配置工具，供迁移前维护已有线上服务。切流前不要卸载 `vueblog.service` 或删除 `/etc/vueblog.env`、原数据库和旧版本。新主机接收器、数据迁移、首次切流和真实回退必须另行验证。

2026-11-18/19 的操作步骤文档保留当时实际路径；其中 `frontend/` 对应这里的 `frontend/`。历史记录不是当前新版启动说明。
