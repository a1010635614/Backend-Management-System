## 创建机器人

使用飞书电脑客户端，进入一个用于博客部署通知的群；没有合适群时先创建。打开群右上角菜单 → 设置 → 群机器人 → 添加机器人，选择“自定义机器人”，名称可填“博客部署通知”，确认添加。

在机器人配置中保存生成的 Webhook 地址，进入安全设置启用“签名校验”，保存对应签名密钥和设置。如果同时配置自定义关键词，使用“纸间博客部署通知”，与当前通知脚本的消息标题一致。

Webhook 和签名密钥均按凭据保管，不要发到聊天、截图、源码或 GitHub。当前优先使用云效内置飞书通知插件，由用户直接填写云效表单；如使用备用 notify.py，则保存为云效加密变量。本机验证工具不持久保存凭据。

## 云效原生通知插件

进入流水线编辑页的流程配置，在“生产部署”任务侧栏底部打开“任务插件 → 添加插件”，选择飞书机器人通知插件。填写已有机器人的 Webhook 和加签密钥，运行状态选择成功、失败、取消；通知内容选择流水线名称、阶段、任务、状态及执行人。构建任务也添加同类插件，但状态只选择失败、取消。参考[官方消息通知说明](https://help.aliyun.com/zh/yunxiao/user-guide/other-plug-ins/)。

自定义内容可填写以下公开部署信息，变量展开需由真实通知核对：

```text
纸间博客部署通知
环境：production
网站：https://kongqi.xyz
分支：${CI_COMMIT_REF_NAME}
提交：${CI_COMMIT_SHA}
运行编号：${BUILD_NUMBER}
```

首次配置完成先仅保存，接 GitHub 提交触发后，用一次新提交验收自动发布及群内通知。第 11 次已通过自动发布和原生插件成功通知验收；用户确认运行编号和提交变量准确。需要界面协助时，只提供尚未填写凭据的表单截图。

## 本机连接验证工具

机器人准备好后，在项目根目录运行 `backend/.venv/Scripts/python.exe deploy/configure_feishu.py`，打开 Blog Feishu configuration。填写目标群名称、遮罩 Webhook 和签名密钥，随后会展示完整测试正文和发送确认。群名称仅供用户核对，真正目标由该 Webhook 绑定的群决定。

取消输入或取消发送确认均不会发消息。确认后只尝试发送一条签名测试通知；遇到超时或不明确结果时，先检查目标群，再决定是否重试。工具不保存凭据，后续需要将同一 Webhook 和签名密钥填入云效的 FEISHU_WEBHOOK、FEISHU_SIGNING_SECRET 加密变量，以便流水线独立发送成功/失败通知。

测试正文预览：

```text
纸间博客部署通知
类型：机器人接入验证
环境：配置测试
网站：https://kongqi.xyz
```

通知命令也支持 `python3 deploy/notify.py success --preview`，仅显示正文，不发送网络请求。实际发送命令要求两项凭据均已配置；凭据不作为命令行参数传递。本机测试已获得目标群收取反馈；当前真实 Flow 使用原生插件，成功通知已验收，失败/取消通知尚未验收。

## 验证及授权范围

配置后先展示完整测试通知正文和目标群名称，由用户确认发送。测试通知应明确标记为接入验证，不能伪装为已完成自动部署。成功发出并由用户确认收取，只能证明机器人通路可用。

完整验收仍需 GitHub 提交触发真实云效运行，成功/失败通知携带该次提交、结果和流水线地址，且与服务器实际版本一致；故障回退和失败通知需分别演练。
